# LocationSpoofer 4.0.1

> 小版本更新：谷歌地图开箱即用，修复谷歌搜索报错，新增「从最近任务中隐藏」。
>
> 2026 年 11 月 15 日更新了安装包：修复软件内更新一直停在 0%。版本号没变，已安装的 4.0.1 不会提示更新，需要手动下载覆盖安装。

[English →](https://github.com/liliwiki/LocationSpoofer/blob/main/docs/release-notes/v4.0.1-en.md)

---

## 更新内容

- **谷歌地图开箱即用**：安装包内置了一个只能显示谷歌地图的 Key，不用自己申请就能看到谷歌地图。这个 Key 只开通了地图显示（免费），不能用于搜索和路线
- **修复谷歌搜索报错**：搜索地点时提示 `9011: You're calling a legacy API` 的问题已修复。谷歌已不再给新项目开通旧版 Places API，现在改用 Places API (New)，Places SDK 从 3.4.0 升级到 6.0.2
- **谷歌 Key 设置改名**：「设置 → 地图配置」里的「谷歌地图 API Key」改为「谷歌搜索 / 路线 API Key」。这里填的 Key 只用于地点搜索和路线规划，申请时需要开通 **Places API (New)** 和 **Routes API**
- **从最近任务中隐藏**：在「设置 → 外观与语言 → 主题」最下面，默认关闭。打开后离开软件，多任务界面里不再显示它，模拟仍在后台运行
- **修复软件内更新停在 0%**：部分手机（如 vivo）的系统下载器连不上 GitHub，会一直重试且不报错。现在由软件自己下载安装包，下载失败时会提示原因

从 4.0.0 及更早的版本在软件内更新时如果一直停在 0%，请到 Release 页面手动下载安装。

## 安装

[v4.0.1 Release 页面](https://github.com/liliwiki/LocationSpoofer/releases/tag/v4.0.1)提供：

- `LocationSpoofer-4.0.1-arm64-v8a.apk`：绝大多数手机用这个
- `LocationSpoofer-4.0.1-armeabi-v7a.apk`：32 位老机型

从 4.0.0 升级：直接覆盖安装。之前填过的谷歌 Key 会保留，继续用于搜索和路线；如果它没有开通 Places API (New)，需要到谷歌云控制台补开。

首次安装和地图 Key 申请说明见 [4.0.0 更新说明](https://github.com/liliwiki/LocationSpoofer/blob/main/docs/release-notes/v4.0.0.md)。
