# LocationSpoofer 4.0.1

> Minor update: Google Maps works out of the box, Google search no longer fails, and a new "Hide from recent apps" option.

[中文 →](https://github.com/liliwiki/LocationSpoofer/blob/main/docs/release-notes/v4.0.1.md)

---

## What's new

- **Google Maps works out of the box**: the APK now includes a key that can only display Google Maps, so you see the map without applying for your own key. That key only has map display enabled (free) and cannot be used for search or routes
- **Google search fixed**: searching for a place no longer fails with `9011: You're calling a legacy API`. Google no longer enables the legacy Places API for new projects, so the app now uses Places API (New), and the Places SDK moved from 3.4.0 to 6.0.2
- **Google key setting renamed**: "Google Maps API Key" in Settings → Map config is now "Google Search / Routes API Key". The key you enter there is only used for place search and route planning; enable **Places API (New)** and **Routes API** for it
- **Hide from recent apps**: at the bottom of Settings → Appearance and language → Theme, off by default. When on, the app no longer shows in the recent apps screen after you leave it; simulation keeps running in the background

Tested on a Pixel 8 Pro (Android 17) in root mode: Google Maps display and Google place search. For "Hide from recent apps", only the system's exclude flag on the task was confirmed; the recent apps screen itself has not been checked on every device.

## Install

The [v4.0.1 release page](https://github.com/liliwiki/LocationSpoofer/releases/tag/v4.0.1) has:

- `LocationSpoofer-4.0.1-arm64-v8a.apk`: for most phones
- `LocationSpoofer-4.0.1-armeabi-v7a.apk`: for older 32-bit phones

Upgrading from 4.0.0: install over the top. A Google key you entered before is kept and still used for search and routes; if it doesn't have Places API (New) enabled, enable it in the Google Cloud console.

For first-time setup and how to apply for map keys, see the [4.0.0 release notes](https://github.com/liliwiki/LocationSpoofer/blob/main/docs/release-notes/v4.0.0-en.md).
